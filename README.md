# Steel Trap — Relational Reasoning & N-Back Suite

A single-file, offline cognitive training suite: multi-modal n-back (position, audio, relational word reasoning, image, color, rotation) with high-interference lure control, per-user local profiles, saved modes, peer challenges, goal tracking, and session analytics with CSV export.

## This commit (v1 snapshot)

This is the **original version generated by Gemini** (the `steel_trap-v2` output, including the Steel Trap logo), preserved verbatim as the project's v1 snapshot before optimization. It is a working prototype, kept for reference and rollback.

Known limitations of this snapshot, documented honestly:

- Local profiles are a **convenience separator, not security**: passwords are stored as unsalted SHA-256 hashes and all data is plain-text browser localStorage. Do not reuse an important password here.
- The "g-Rating," brain-region percentages, and goal "prescriptions" are **heuristic formulas**, not validated measures of intelligence, brain activity, or medical guidance.
- Several features were dropped or changed across the Gemini iterations that produced this file; an optimized merged build is developed on a separate branch via pull request.

## Running it

Download `steel-trap.html` and open it in any modern browser. No server, install, or internet connection required.

## Workflow

- `main` = official version. Experiments land on branches and are reviewed via pull requests.
- Approved versions are snapshotted so earlier iterations always remain accessible.
